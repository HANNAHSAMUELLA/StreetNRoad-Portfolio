# Technology Stack

The following technologies have been used across StreetNRoad's application, integration and infrastructure work. Not every technology is used by every module.

| Area | Technologies / services | Use |
|---|---|---|
| Web interface | HTML, CSS, JavaScript | Browser-based application interfaces |
| Backend services | Python, Flask, Node.js | Application APIs and service workflows |
| Data storage | MySQL, PostgreSQL, SQLite | Relational and service-level data storage in different components |
| Real-time communication | Socket.IO | Selected live update capabilities |
| Messaging | WhatsApp Business Platform / Cloud API | Business notifications and document workflows |
| Maps and geospatial | Mapbox, OpenStreetMap | Geocoding and map presentation |
| Routing | OSRM | Route and distance-related workflows |
| Web serving | Nginx | Reverse proxy and web serving |
| Operating environment | Ubuntu Linux | Server environment |
| Hosting | DigitalOcean | Cloud infrastructure |
| Delivery model | Progressive Web App (PWA) | Installable, browser-accessible experience |

## Stack notes

- This is a high-level inventory of technologies used across different project components.
- It is not a complete dependency manifest.
- Versions and deployment configurations are intentionally omitted.
- No credentials, API tokens, private endpoints or infrastructure identifiers belong in this portfolio.
